# VoiceEmotionApp

VoiceEmotionApp - настольное Windows-приложение для распознавания эмоций по голосу.
Оно позволяет собрать собственный аудиодатасет, проверить качество записей, обучить
несколько классификаторов, сравнить их по единым метрикам и распознавать эмоции в
файлах или речи с микрофона. Дополнительный FastAPI-сервис публикует версии моделей
и принимает обезличенные события для агрегированной статистики.

## Что умеет приложение

- загружает CSV-датасеты и сопоставляет произвольные метки с семью эмоциями;
- проверяет пути, формат, длительность и качество аудиозаписей;
- записывает original и processed версии голоса в структурированный датасет;
- восстанавливает переносимый CSV по существующим аудиофайлам;
- извлекает 416 фиксированных статистик MFCC, delta-MFCC, chroma, mel, pitch и спектральных признаков;
- обучает SVM, Random Forest, PyTorch MLP и вероятностные ансамбли;
- сохраняет модель, параметры preprocessing, метрики, текстовый отчёт и историю SQLite;
- пропускает повторный эксперимент, если датасет и настройки не изменились;
- распознаёт отдельный WAV/MP3, папку файлов или длинную запись с микрофона;
- делит длинную речь на пятсекундные фрагменты и рассчитывает общий эмоциональный фон;
- выполняет длительные операции в фоновых Qt-потоках.

## ML-методика

Конвейер разделяет настройку моделей и итоговую оценку, чтобы результаты разных
алгоритмов можно было сравнивать на одних и тех же данных.

1. Метки эмоций кодируются одним `LabelEncoder`.
2. Train и test разделяются по непересекающимся `speaker_id`. Алгоритм перебирает
   групповые разбиения и выбирает вариант с лучшим покрытием классов.
3. Из train тем же способом выделяется validation. Test после этого используется
   только один раз для итоговой оценки.
4. Кросс-валидация использует `StratifiedGroupKFold`. `StandardScaler` и
   `SelectKBest` входят в `sklearn.Pipeline` и переобучаются внутри каждого фолда.
5. Параметры SVM и Random Forest подбираются по macro F1 внутри fit. Для MLP
   внутри fit создаётся отдельная tuning-часть, поэтому общая validation не участвует
   в выборе архитектуры нейросети.
6. Веса ансамбля по каждому классу рассчитываются на validation-предсказаниях
   моделей, которые не обучались на этой части данных.
7. Лучшая модель выбирается по validation macro F1. Test не участвует ни в выборе
   алгоритма, ни в подборе параметров.
8. Для сравнения сохраняются accuracy, balanced accuracy, macro/weighted F1,
   precision, recall, confusion matrix, CV-разброс, время inference и разрыв train/test.

Экстрактор всегда возвращает одну схему из 416 признаков. Если расчёт отдельной
группы признаков завершается ошибкой, вместо неё используется блок нулей той же
размерности. Модель с другой версией схемы требует переобучения: дополнять или
обрезать векторы автоматически нельзя, поскольку столбцы потеряют исходный смысл.

Если корректных `speaker_id` недостаточно, приложение использует стратифицированное
разбиение по эмоциям и явно добавляет в отчёт предупреждение о возможной
оптимистичности метрики.

## Архитектура

- `app/ui` содержит главное окно и вкладки PySide6.
- `app/services` выполняет сценарий обучения.
- `app/ml` содержит модели, оценку и сохранение результатов.
- `app/audio.py`, `app/microphone.py` и `app/recorder.py` работают со звуком.
- `app/dataset.py` и `app/dataset_recovery.py` работают с датасетами.
- `app/features.py` извлекает акустические признаки.
- `app/recognizer.py` выполняет распознавание.
- `app/storage.py` хранит историю и формирует отчеты.
- `server` содержит FastAPI-сервис и Docker Compose.
- `tests` содержит проверки основных компонентов.

Связи между модулями и основные сценарии описаны в
[`docs/PROJECT_MAP.md`](docs/PROJECT_MAP.md).

## Установка и запуск

Рекомендуется 64-битный Python 3.11. Виртуальное окружение создается в каталоге
LocalAppData пользователя. Короткий путь снижает риск ошибки Windows Long Path при
установке PySide6.

```bat
install.bat
run.bat
```

Можно сразу запустить `run.bat`: недостающие runtime-зависимости установятся
автоматически. Для сборки исполняемого файла используется отдельная команда:

```bat
build_exe.bat
```

PyInstaller устанавливается только при сборке и не утяжеляет обычную установку.
При первом запуске приложение создаёт локальный `config.json` из встроенных значений;
этот машинный файл исключён из Git, а публикуемый пример находится в
`config.example.json`.
Датасеты, обученные модели, кеш, журналы и отчёты перечислены в `.gitignore`: в
публичный репозиторий попадают код и пустая структура каталогов, но не локальные данные.

## Формат датасета

Минимальный CSV содержит путь к записи и эмоцию:

```csv
file_path,emotion,speaker_id
records/speaker_001_joy.wav,joy,speaker_001
records/speaker_002_calm.wav,calm,speaker_002
```

Дополнительно поддерживаются `gender`, `age_group`, `recorded_at`, `duration`,
`sample_rate`, `source`, `text`, `language`, `quality` и `original_path`. Относительные
пути вычисляются от папки CSV. Для группового разбиения каждой записи нужен
стабильный `speaker_id`.

Пользовательские записи находятся в каталоге `datasets/user_dataset`. Для каждого
диктора и эмоции создаются отдельные папки `original` и `processed`.

Правило минимальной длительности проверяется по original-записи. После удаления
тишины processed-файл может быть короче исходного и остаётся допустимым.

## Тесты

Зависимости для разработки устанавливаются отдельно:

```bat
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
```

Сервер имеет собственные зависимости и тесты:

```bat
python -m pip install -r server\requirements.txt pytest
set PYTHONPATH=server
python -m pytest server\tests -q
```

## Технические особенности

- качество определяется объёмом, балансом и разнообразием голосов в датасете;
- MP3 зависит от доступного аудиобэкенда, поэтому для воспроизводимой демонстрации
  предпочтителен WAV mono 16 кГц;
- обучение MLP на CPU работает, но занимает больше времени; CUDA включается только
  при совместимой видеокарте и сборке PyTorch;
- joblib-модели следует загружать только из доверенного источника и той же версии
  scikit-learn, в которой они были сохранены;
- модели с другой версией схемы признаков требуется переобучить;
- серверная часть опциональна и не требуется для локального обучения и распознавания.
